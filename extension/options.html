One-time GitHub setup

This extension needs a GitHub Personal Access Token to trigger your screenshot workflow. You only do this once — it's saved locally and reused for every future test.

  1. Go to github.com/settings/tokens?type=beta
  2. Click Generate new token (fine-grained)
  3. Scope it to only your cross-os-tester repo
  4. Grant Actions: Read & Write and Contents: Read permissions
  5. Paste the token and your repo details below
