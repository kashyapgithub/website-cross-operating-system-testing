cross-os

One-time GitHub Setup

This extension uses your GitHub repository and cloud Actions runners to capture screenshots across Windows, macOS, and Linux for free. Your token is stored locally in your browser and never leaves your machine.

Step 1: Create a Personal Access Token

Choose whichever token type you prefer:

Option A: Classic Token (Fastest — 1 Click)

Creates a classic token with the repo scope pre-selected.

Create Pre-filled Classic Token ↗

Option B: Fine-grained Token (Scoped)

Go to github.com/settings/tokens?type=beta, scope to your repo, and grant:

  • Actions: Read and write
  • Contents: Read and write

Step 3: How to Test Any UI

  1. Open any website in Google Chrome that you want to test (HTTP or HTTPS).
  2. Click the Cross-OS Tester icon in your browser toolbar to open the popup.
  3. Configure capture mode: Select Full page or Visible area, and check the target browsers (Chrome, Firefox, Safari/WebKit).
  4. Click "Run test": Runners spin up on Windows, macOS, and Linux in the cloud and stream results back live.
  5. Inspect & Compare:
    • Click ⤢ (Maximize) to pop out into a full-window multi-column comparison studio.
    • Click Expand all to view all 9 screenshots side-by-side.
    • Click any screenshot to open the full-resolution Lightbox zoom modal.
